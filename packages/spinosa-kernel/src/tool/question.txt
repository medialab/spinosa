Use this tool when a blocking decision belongs to the user. After elaborating the prompt, ask only to:
1. Confirm or correct the elaborated scope
2. Request missing data the user must supply
3. Resolve real ambiguity that would change the analysis or deliverable

Do not ask ritual, filler, or “questions for their own sake.” Skip the tool when the elaborated reading is already clear and actionable.

Usage notes:
- Ask 1 to 3 questions in one turn. Prefer concrete options; put a recommended option first when applicable.
- Do not ask a fourth question. Do not chain extra question calls for the same task.
- When `custom` is enabled (default), a "Type your own answer" option is added automatically; don't include "Other" or catch-all options
- Answers are returned as arrays of labels; set `multiple: true` to allow selecting more than one
- If you recommend a specific option, make that the first option in the list and add "(Recommended)" at the end of the label
